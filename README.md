# Page View Time Series Visualizer

A time-series data science project completed for the **Data Analysis with Python** certification on **freeCodeCamp**.

This project analyzes and visualizes the daily traffic and page view counts of the freeCodeCamp.org forum over a multi-year timeline (2016 to 2019). It uncovers underlying growth trajectories, yearly expansions, and recurring monthly seasonality behaviors.

## 📊 Visualizations Built

1. **Chronological Line Chart (`line_plot.png`)**: Traces the fluid, uninterrupted historical movement of daily traffic across the entire timeline.
2. **Grouped Monthly Bar Chart (`bar_plot.png`)**: Compares structural yearly shifts by evaluating average daily page views for each explicit month clustered chronologically.
3. **Dual Box Plots (`box_plot.png`)**: Juxtaposes a Year-wise trend analysis with a Month-wise seasonal dispersion check to demonstrate how values vary over time.
